// 01 · Infrastructure

Homelab — Self-Hosted Stack

37 Docker containers in production: password manager, document management with OCR, file cloud, workflow automation and my own apps — every service reachable from the internet without a single open port forwarding. Traffic runs through a Cloudflare Tunnel, and sensitive services sit behind my own 2FA login portal (Authelia, TOTP).

●dashboard.erdembasar.de
Highlights
  • Zero-trust access: Cloudflare Tunnel + Authelia 2FA portal, reverse proxy with Caddy (forward_auth)
  • Backups: restic, encrypted, to two targets (local + Cloudflare R2), consistent DB dumps, restore tests, dead man's switch via Healthchecks
  • Security alerts: a PowerShell task evaluates the Windows event log and container logs → push notification to my phone with a "ban IP" button that blocks the attacker at the Cloudflare edge via an n8n webhook
  • Monitoring: Uptime Kuma, Beszel metrics, Dozzle logs, ntopng traffic analysis per container
  • Maintenance: image update alerts (Diun), central log rotation, health checks per service

// 02 · Own development

StreamingTools — Twitch Command Center

My largest own development: a web app that runs an entire Twitch channel on data. It collects market data through the Twitch API around the clock, calculates the best broadcast times from thousands of measurements and manages title, category and tags live via EventSub — including an AI title generator, automatic clip detection when the chat gets hyped, and Discord announcements.

●streamingtools — Dashboard
Highlights
  • Timing Optimizer: heatmap of the best broadcast times, built from thousands of automatically collected viewer/streamer measurements
  • Stream Manager: title, category, tags, predictions and ads straight from the app — events in real time via Twitch EventSub
  • Clip Highlighter: detects hype moments in chat and creates clips automatically
  • AI title generator: suggestions based on the currently most successful streams in the category
  • Raid tools: raid candidates scored by size, language and raid history

PreisAlarm — Price Tracking

Open web tool ⬡ GitHub

Watches wishlist products automatically across Geizhals, PriceSpy & Amazon and reports price drops by e-mail, Discord and web push. It comes in two flavours: an open-source Windows app (MIT licence) and a self-hosted web tool with multi-user login, price history and budget search.

●preisalarm.erdembasar.de
Highlights
  • Scraping engine: Selenium + headless Chromium checks more than 50 shops on a configurable interval (APScheduler)
  • Notifications: e-mail, Discord webhook and web push (VAPID) — also installable as a PWA
  • Price history & forecast: charts per product, AI-assisted buy recommendation
  • Multi-user: registration, password reset, admin area, CSRF protection

// 04 · Community platform

Predecessor Inhouse League

View live

A complete league platform for community matches in the MOBA Predecessor: players join the queue with a Discord command, an embedded Discord bot automatically builds fair 5v5 teams with minimal MMR difference, and results feed into a Glicko-2 rating — the leaderboard and all player profiles are public on the website.

●inhouse.edoeasy.live
Highlights
  • One process, two roles: the discord.py bot runs as an asyncio task inside the FastAPI lifespan — same event loop, shared database
  • Matchmaking: team balancing by brute-force search for the smallest MMR difference, ready check in the channel
  • Glicko-2 implemented from scratch and verified against the inventor's reference example
  • Draft system: pick/ban pages with a spectator view and an OBS overlay for streams
  • Admin via Twitch OAuth: a login whitelist instead of passwords
